# Cisco Packet Tracer Networking & Cybersecurity Labs

## 📌 Project Overview

This repository contains hands-on networking and cybersecurity lab files created using Cisco Packet Tracer. These labs are intended to develop practical skills in network configuration, connectivity testing, troubleshooting, and network security fundamentals.

## 🎯 Objectives

- Understand network devices and network topologies.
- Practice router and switch configuration.
- Learn IP addressing and subnetting.
- Explore network connectivity and troubleshooting.
- Practice basic network security concepts.
- Build practical skills relevant to Network Engineer, NOC Engineer, and Cybersecurity roles.

## 🛠️ Tools & Technologies

- Cisco Packet Tracer
- Routers and switches
- IPv4 addressing and subnetting
- TCP/IP networking
- Network troubleshooting commands
- Basic network security concepts

## 🚀 How to Run the Labs

1. Install Cisco Packet Tracer.
2. Download or clone this repository.
3. Open Cisco Packet Tracer.
4. Select **File → Open** and choose a `.pkt` file.
5. Inspect the network topology and device configurations.
6. Test connectivity using commands such as `ping` and `tracert`.
7. Verify the results against the lab objectives.

## 🧪 Testing & Validation

Depending on the lab configuration, testing may include:

- Verifying IP addresses and subnet masks.
- Checking router and switch interfaces.
- Testing communication between PCs.
- Inspecting routing tables and VLAN assignments.
- Checking access restrictions and security configurations.
- Troubleshooting connectivity failures.
